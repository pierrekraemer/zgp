# SurfaceMesh

[`src/models/surface/SurfaceMesh.zig`](../../src/models/surface/SurfaceMesh.zig) is the richest geometric model in `zgp`, representing an orientable 2-manifold surface mesh (with or without boundary) as a **2-dimensional combinatorial map** (2-map), accompanied by 23 algorithm and helper files in [`src/models/surface/`](../../src/models/surface/).

---

## 1. Combinatorial Map Representation

### Darts and Relations ($\phi_1$, $\phi_{-1}$, $\phi_2$)

The atomic topological element is a **`Dart`** (`u32` index into `dart_data`). Every dart carries a `DartProps` record:

```zig
const DartProps = struct {
    phi1: Dart,      // next dart around the incident face
    phi_1: Dart,     // previous dart around the incident face
    phi2: Dart,      // opposite dart across the incident edge (involution: phi2(phi2(d)) == d)
    vertex: Vertex,  // cell index in vertex_data
    edge: Edge,      // cell index in edge_data
    face: Face,      // cell index in face_data (invalid_index for boundary darts)
    boundary: bool,  // true iff this dart belongs to a virtual boundary face
};
```

```text
                        v2
                       /  ^
                      /    \
                     /      \
          phi_1(d)  /        \  phi1(d)
                   /     f    \
                  /            \
                 v       d      \
                v0 ------------> v1
                   <------------
                      phi2(d)
```

Each topological cell is an **orbit** of darts generated by composing these permutations:

| `CellType` | Alias | Orbit Traversal | Backing `DataContainer` | Representative Dart |
|---|---|---|---|---|
| `.halfedge` | `Halfedge` | `{d}` (single dart) | `dart_data` | `c.index` itself |
| `.corner` | `Corner` | `{d}` (single dart) | `dart_data` | `c.index` itself |
| `.vertex` | `Vertex` | `d -> phi2(phi_1(d))` (outgoing darts) | `vertex_data` | `vertex_dart` |
| `.edge` | `Edge` | `{d, phi2(d)}` | `edge_data` | `edge_dart` |
| `.face` | `Face` | `d -> phi1(d)` | `face_data` | `face_dart` |

- **Typed cell indices**: `Cell(cell_type)` wraps `index: u32` with a comptime `CellType`, preventing accidental mixing of vertex, edge, and face indices.
- **Bidirectional lookup**:
  - Dart → Cell: `sm.cell(d, cell_type)` or convenience `sm.halfedge(d)`, `sm.corner(d)`, `sm.vertex(d)`, `sm.edge(d)`, `sm.face(d)`.
  - Cell → Representative Dart: `sm.dart(cell)`.
- **$O(1)$ degree & codegree**: Because `setDartCell` maintains `DataContainer` reference counts (`refIndex`/`unrefIndex`) for every dart attached to a vertex/edge/face:
  - `sm.degree(v)` reads `vertex_data.nb_refs.value(v.index)` in $O(1)$.
  - `sm.codegree(f)` reads `face_data.nb_refs.value(f.index)` in $O(1)$.

### Boundary Representation

Open mesh borders are explicitly closed by **virtual boundary faces** during `sm.close()`:
- Every boundary loop becomes a $\phi_1$-cycle of darts with `boundary = true`, sewn via $\phi_2$ to the interior border darts.
- Boundary darts have valid `vertex` and `edge` cells, but **`face.index == invalid_index`** (boundary faces are *not* indexed in `face_data`).
- Representative darts (`vertex_dart`, `edge_dart`, `face_dart`) are **always non-boundary darts**.
- `sm.nb_boundary_darts` is cached and refreshed by `SurfaceMeshStore.surfaceMeshConnectivityUpdated()`; `nbCells(.halfedge)` and `nbCells(.corner)` return `dart_data.nbElements() - nb_boundary_darts`.

> **Gotcha:** `dartIterator()`, `halfedgeIterator()`, and `cornerIterator()` iterate over **all** active darts in `dart_data`, **including boundary darts**. Likewise, `vertexDartIterator()` and `edgeDartIterator()` (i.e., `orbitDartIterator(..., .vertex | .edge)`) also yield any boundary dart belonging to the vertex or edge orbit. Always check `if (sm.isBoundaryDart(d)) continue;` whenever an operation assumes an interior dart (e.g., accessing `sm.face(d)` or interior halfedge/corner data).

## 2. Core API & Topological Operators

### Iterators, Markers, Data, CellSets & Parallelism

- **Global iterators**: `dartIterator()`, `cellIterator(cell_type)` (`halfedgeIterator`, `cornerIterator`, `vertexIterator`, `edgeIterator`, `faceIterator`). All expose `next()`, `nextSafe()` (safe during deletion), and `reset()`.
- **Orbit iterators**: `orbitDartIterator(d, cell_type)` (`vertexDartIterator`, `edgeDartIterator`, `faceDartIterator`), plus `orbitNonBoundaryDart(d, cell_type)` and `dartBelongsToOrbit(d1, d2, cell_type)`.
- **Markers**: `DartMarker` (with `markOrbit`/`unmarkOrbit`) and `CellMarker(cell_type)` (`VertexMarker`, `EdgeMarker`, `FaceMarker`), backed by pooled `DataContainer` markers.
- **Typed Cell Data**: `CellData(cell_type, T)` (`HalfedgeData`, `CornerData`, `VertexData`, `EdgeData`, `FaceData`) via `addData`, `addDataWithUniqueRandomName`, `getData`, `getOrAddData`, `removeData`.
- **CellSets**: `CellSet(cell_type)` (`VertexSet`, `EdgeSet`, `FaceSet`) managed via `addCellSet`, `getCellSet`, `getOrAddCellSet`, `removeCellSet`. Backed by a `CellMarker` + `ArrayList` of cells; `cs.update()` rebuilds the list after topology edits (called automatically in `SurfaceMeshStore.surfaceMeshConnectivityUpdated`).
- **Cloning**: `clone(allocator)` copies topology + all cell data (not markers or CellSets); `cloneWithoutCellData(allocator)` copies only topology and container slot layout (used by `ITContext` to keep matching vertex indices).
- **Parallel Runners**: `ParallelCellTaskRunner(cell_type)` and `ParallelCellTaskRunnerWithContext(cell_type, Context)` (`ParallelHalfedge/Corner/Vertex/Edge/FaceTaskRunner*`), thin wrappers around `DataContainer.ParallelIndexTaskRunner*`.
- **Integrity Check**: `sm.checkIntegrity()` verifies $\phi_1$/$\phi_{-1}$/$\phi_2$ consistency, boundary face invariants, orbit-to-cell bijection, non-boundary representative darts, minimum dart counts (vertex $\ge 2$, edge $= 2$, face $\ge 3$), and `nb_refs` accuracy. Automatically executed in `.debug` builds by `SurfaceMeshStore.loadSurfaceMeshFromFile` and `surfaceMeshConnectivityUpdated`.

### Low-Level / Creation Operators

These operators manipulate darts directly and **do not** maintain cell indices (call `close()` and `initCells()` after construction, as done in `SurfaceMeshStore.loadSurfaceMeshFromFile`). Primitive sewing helpers: `phi1Sew`, `phi2Sew`, `phi2Unsew`, `addCell`, `setDartCell`, `initCells`.

#### `addUnboundedFace(nb_vertices) -> Dart`
Creates a standalone $\phi_1$-cycle of `nb_vertices` darts whose $\phi_2$ links point to themselves.

```text
            v2
           /  ^
       d2 /    \ d1
         v      \
        v0 ----> v1
            d0         (phi2(d_i) = d_i; no cell indices assigned)
```

#### `removeFace(f)`
Unsews $\phi_2$ along every dart of face `f` and deletes all darts of `f`, leaving an open hole (neighboring opposite darts become $\phi_2$-fixed).

```text
    +----<----+             +----<----+
    |  face f |             |  hole   |  (border darts now have phi2(d) = d;
    |  (del)  |    ===>     | (open)  |   cell indices are not updated)
    +---->----+             +---->----+
```

#### `closeHoleWithPolygon(d) -> Dart` & `close() -> u32`
Walks open border darts ($\phi_2(x) = x$) around a hole and creates a single polygonal face sewn via $\phi_2$ to the hole border. `close()` scans the whole mesh, calls `closeHoleWithPolygon` on every open boundary loop, and marks all created darts as boundary darts (`boundary = true`, `face = invalid_index`).

```text
  Before (open hole, phi2(x)=x):     After closeHoleWithPolygon(d) / close():

         v1 ------> v2                     v1 ------> v2
         ^   hole    |                     ^  <-----   |
         |           v        ===>         | | b_face| v
         v0 <------ v3                     v0  -----> v3
              d                               <------
                                                 d
  (New darts form a CCW cycle inside the hole, sewn via phi2 to each border dart.)
```

### High-Level Topological Operators

These operators preserve valid combinatorial-map invariants and keep all cell indices and non-boundary representative darts up to date.

#### `closeHoleWithUmbrella(d) -> Vertex`
Closes an open hole (starting from a dart `d` with $\phi_2(d) = d$) with a triangle fan meeting at a new central vertex `cv`.

```text
  Before (open hole):           After closeHoleWithUmbrella(d):

     v1 ------> v2                 v1 ------- v2
     ^   hole    |                 | \   f  / |
     |           v      ===>       |  \ cv /  |   (new central vertex cv,
     v0 <------ v3                 | /  \/  \ |    k new radial edges,
          d                        v0 ------- v3   k new triangular faces)
```

#### `addPyramid(baseSize) -> Face`
Creates a closed pyramid with a `baseSize`-sided polygonal base face `bf` and `baseSize` triangular side faces meeting at tip vertex `tv`.

```text
             tv
           / | \
          / / \ \
         v3-----v2
         | \   / |     base face bf = (v0, v1, v2, v3)
         |  bf   |     baseSize triangular side faces meeting at tv
         v0-----v1
```

#### `cutEdge(e) -> Vertex`
Inserts a new vertex `v` into edge `e = {d, dd}` (returning `v` with representative dart `d1`). Original edge `e` is kept on `{d, dd1}`; a new edge `e'` is created on `{d1, dd}`.

```text
  Before:                            After cutEdge(e):

           f1                                   f1
        d (e)                               d (e)    d1 (e')
  v0 ==========> v1                  v0 ======> v ======> v1
  v0 <========== v1       ===>       v0 <====== v <====== v1
       dd (e)                              dd1 (e)   dd (e')
           f2                                   f2
```

#### `canFlipEdge(e)` / `flipEdge(e)` and `canUnflipEdge(e)` / `unflipEdge(e)`
Rotates an interior edge `e = {d, dd}` within its two incident faces (`canFlipEdge` / `canUnflipEdge` forbid boundary edges and edges incident to a degree-2 vertex). `flipEdge` advances endpoints along $\phi_1$ (CCW); `unflipEdge` moves them along $\phi_{-1}$ (CW, exact inverse on general polygons).

```text
  Before (e = {d, dd}):        flipEdge(e) (CCW):          unflipEdge(e) (CW):

          v2                          v2                          v2
         /  \                        /|\                         /|\
    d_1 / df \ d1               d_1 / | \ d1                d_1 / | \ d1
       /  d>  \                    /  ^  \                     /  |  \
      v0======v1        ===>      v0 df|ddf v1      or        v0 ddf|df v1
       \ <dd  /                    \ d|dd/                     \dd|d /
    dd1 \ddf / dd_1             dd1 \ | v dd_1              dd1 \ v | / dd_1
         \  /                        \|/                         \|/
          v3                          v3                          v3

  flipEdge:   d: v3 -> v2, dd: v2 -> v3  (df = {d, d_1, dd1}, ddf = {dd, dd_1, d1})
  unflipEdge: d: v2 -> v3, dd: v3 -> v2  (ddf = {dd, d_1, dd1}, df = {d, dd_1, d1})
```

#### `canCollapseEdge(e)` / `collapseEdge(e) -> Vertex`
Merges `v0 = vertex(d)` and `v1 = vertex(dd)` into `v0`, removes edge `e = {d, dd}`, and deletes any incident non-boundary triangular face (merging its two remaining edges into one). Incident polygonal faces ($\ge 4$ sides) and boundary faces simply lose one dart. `canCollapseEdge` enforces 4 topological link/boundary safety conditions plus a `degree(v0) + degree(v1) <= 15` guard.

```text
  Before:                              After collapseEdge(e):

        v2                                    v2
       /  \                                   |
  e_L / df \ e_R                              | e_R (merged with e_L)
     /  d>  \                                 |
    v0======v1           ===>                 v0 (keeps v0's index)
     \ <dd  /                                 |
 e'_R \ddf / e'_L                             | e'_R (merged with e'_L)
       \  /                                   |
        v3                                    v3
```

#### `cutFace(d1, d2) -> Edge`
Splits a non-boundary polygon (`codegree > 3`) with a new edge `e = {d_1, d_2}` connecting `vertex(d1)` and `vertex(d2)`. The face on `d1`'s side keeps the original `Face` index `f`; the face on `d2`'s side gets a new `Face` index `f'`.

```text
  Before (face f):                     After cutFace(d1, d2):

        v3 <----- v2                         v3 <----- v2
        |    d2    ^                         |    d2  / ^
        |          |                         |  f'   /  |
        |    f     |        ===>             |     d_1  |
        |          |                         |    /  f  |
        v          |                         v  d_2     |
        v0 -----> v1                         v0 -----> v1
             d1                                   d1

  New edge e = {d_1, d_2}: d_1 (v0 -> v2) in new face f', d_2 (v2 -> v0) in original face f.
```

#### `removeVertex(v)`
Removes an interior vertex `v` and all its incident edges, merging its incident faces into a single polygonal face `f`. *(Boundary vertices are not yet handled.)*

```text
  Before:                              After removeVertex(v):

        v2 ----- v1                          v2 ----- v1
       /  \  f1 /  \                        /           \
      / f2 \   / f0 \                      /             \
     v3----- v -----v0       ===>         v3      f       v0
      \ f3 /   \ f5 /                      \             /
       \  /  f4 \  /                        \           /
        v4 ----- v5                          v4 ----- v5
```
