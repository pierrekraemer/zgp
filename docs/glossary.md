# Glossary & Shared Vocabulary

This glossary defines the canonical terms used across the `zgp` codebase and documentation so human contributors and AI agents refer to every concept consistently.

---

## Application & Architecture

- **`AppContext`** (`src/AppContext.zig`): The single root application object owning `io`, `allocator`, `rng`, `window`, `view`, all model stores, `selected_model`, and all concrete modules.
- **`ModelSelection` / `ModelType`** (`src/AppContext.zig`): Tagged union representing the single currently selected model in the UI (`.none`, `.surface_mesh`, `.point_cloud`, `.incidence_graph`). Controls which store's `leftPanel()` and which modules' UI/events are active.
- **Model Store** (`SurfaceMeshStore`, `PointCloudStore`, `IncidenceGraphStore`, planned `VolumeMeshStore`): Central registry and owner for all models of a given family. Manages model lifecycle, per-model `*Info` metadata (standard datas, spatial indices, primitive IBOs), lazy GPU `VBO`/`IBO` caches, update timestamps, and listener notification.
- **Module** (`src/modules/Module.zig`): A self-contained feature unit (renderer, standard-data manager, or interactive algorithm) registered with `AppContext`. Uses a static `VTable` and Zig's `@fieldParentPtr("module", m)` for type-erased dispatch of store, UI, rendering, and SDL events.
- **`SupportedModels`** (`Module.SupportedModels`): Struct of booleans declaring which model types a `Module` applies to. If all flags are `false`, the module is treated as global; otherwise `AppContext.shouldCallOnModule()` only dispatches UI and SDL events to it when the selected model matches.

---

## Data Storage & Parallelism

- **`DataContainer`** (`src/utils/data.zig`): An index-based Structure-of-Arrays (SoA) container managing synchronized typed attribute arrays (`Data(T)`), pooled boolean markers, an active/inactive free-list (`__is_active`, `__nb_refs`), and reference-counted index lifetime (`refIndex`/`unrefIndex`). Indices are **not** guaranteed to be contiguous after deletions.
- **`Data(T)`** (`src/utils/data.zig`): A single typed `ArrayList(T)` attribute column owned by a `DataContainer`, synchronized in length with the container's `size`.
- **`DataGen`** (`src/utils/data.zig`): Type-erased interface header embedded inside every `Data(T)`. Holds `name`, owning `container`, comptime `type_id`, and a `VTable` (`deinit`, `ensureSize`, `clearRetainingCapacity`, `clone`). Used as the map key for GPU `VBO` caches and `data_last_update` timestamps in stores.
- **Marker** (`DataContainer.acquireMarker`, `DartMarker`, `CellMarker`): A pooled, thread-safely acquired `*Data(bool)` array automatically cleared on acquisition and reused on release (`defer marker.deinit()`).
- **`BufferPool(T)`** (`src/utils/BufferPool.zig`): Thread-safe LIFO pool of fixed-size slices owned by each Store and shared across all models in that store.
- **`Parallel*TaskRunner`** (`SurfaceMesh.ParallelCellTaskRunner`, `ParallelCellTaskRunnerWithContext`, `PointCloud.ParallelPointTaskRunner`): Double-buffered work-batching runner using `BufferPool` and two `std.Io.Group`s to evaluate per-cell or per-point tasks across worker threads.

---

## Standard Datas & Reactive Updates

- **Standard Data (`StdData` / `StdDatas`)**: A predefined semantic slot in a model's `*Info.std_datas` struct (e.g., `vertex_position`, `face_normal`, `halfedge_cotan_weight` on `SurfaceMesh`; `position`, `normal`, `radius` on `PointCloud`). Maps a well-known geometric role to an arbitrary named `CellData`/`PointData` on the model.
- **`*StdData` Tagged Union**: Auto-generated at comptime via `types.UnionFromStruct(*StdDatas)` so callers can update a single standard slot through `store.set*StdData(model, .{ .vertex_normal = data })`.
- **`data_last_update`**: Per-store map from `*const DataGen` to `std.Io.Timestamp`, updated whenever `store.*DataUpdated(...)` is called. Drives automatic staleness detection for derived `StdDatas`, `TrianglesBVH`, and `PointsKDTree`.

## Topological Models

### SurfaceMesh (2-Manifold Combinatorial Map)
- **Combinatorial Map (2-Map)**: Topological representation of an orientable 2-manifold surface built from **darts** and permutations $\phi_1$ (`phi1`), $\phi_{-1}$ (`phi_1`), and involution $\phi_2$ (`phi2`).
- **Dart (`SurfaceMesh.Dart = u32`)**: Atomic topological element (conceptually an oriented halfedge attached to a face and its origin vertex). Index into `dart_data`.
- **$\phi_1$ (`phi1`) / $\phi_{-1}$ (`phi_1`)**: Next / previous dart around a face cycle (CCW for interior faces, CW around holes for boundary faces).
- **$\phi_2$ (`phi2`)**: Opposite dart across an undirected edge ($\phi_2(\phi_2(d)) = d$, $\phi_2(d) \neq d$ in a valid closed map).
- **Orbit**: The set of darts forming a single topological cell, generated by composing map permutations:
  - **Halfedge** / **Corner**: single dart $\{d\}$.
  - **Vertex**: cycle under $\phi_2 \circ \phi_{-1}$ (all outgoing darts from the vertex).
  - **Edge**: pair $\{d, \phi_2(d)\}$.
  - **Face**: cycle under $\phi_1$.
- **Cell (`SurfaceMesh.Cell(cell_type)`)**: Typed index wrapper (`Halfedge`, `Corner`, `Vertex`, `Edge`, `Face`) preventing accidental mixing of cell dimensions.
- **Representative Dart** (`vertex_dart`, `edge_dart`, `face_dart`): A single canonical **non-boundary** dart stored per vertex, edge, and face cell, allowing $O(1)$ lookup from a cell to its orbit.
- **Boundary Dart / Boundary Face**: Open mesh boundaries are closed during `SurfaceMesh.close()` by virtual polygonal faces whose darts have `boundary = true` and `face.index = invalid_index`. Boundary faces are **not** indexed in `face_data`, ensuring every dart still satisfies $\phi_2(d) \neq d$ while keeping interior face counts exact.
- **`CellData(cell_type, T)`**: Typed handle wrapping a `*Data(T)` on a specific cell `DataContainer` (`HalfedgeData`, `CornerData`, `VertexData`, `EdgeData`, `FaceData`). Note that `HalfedgeData` and `CornerData` live in `dart_data`.
- **`CellSet(cell_type)` / `CellSetGen`**: Named subset of `Vertex`, `Edge`, or `Face` cells backed by both a `CellMarker` ($O(1)$ membership) and a dense `ArrayList` of cells (for iteration and GPU `IBO` rendering). Automatically rebuilt during `SurfaceMeshStore.surfaceMeshConnectivityUpdated()`.
- **Degree / Codegree**:
  - `degree(cell)`: Number of $(d+1)$-dimensional incident cells (for a vertex: incident edges = `nb_refs` in $O(1)$; for an edge: 1 on boundary, 2 interior).
  - `codegree(cell)`: Number of $(d-1)$-dimensional incident cells (for an edge: 2; for a face: number of vertices/edges = `nb_refs` in $O(1)$).
- **`SurfacePoint`** (`src/models/surface/SurfacePoint.zig`): An intrinsic location on a `SurfaceMesh` — either a `.vertex`, a point along an `.edge` (`dart`, parameter $t \in [0, 1]$), or a point inside a `.face` (`dart`, barycentric coordinates).
- **Intrinsic Triangulation (`ITContext`)**: A cloned combinatorial triangulation (`intrinsic_surface_mesh`) sharing vertex indices with the fixed `extrinsic_surface_mesh`, storing intrinsic edge lengths and signpost angles so edges can be flipped (Delaunay, FlipOut) or refined without altering the 3D embedding.

### PointCloud & IncidenceGraph
- **`PointCloud`** (`src/models/point/PointCloud.zig`): Unstructured set of `Point` (`u32`) indices backed by a single `DataContainer` (`point_data`) and `PointData(T)` handles.
- **`IncidenceGraph`** (`src/models/incidenceGraph/IncidenceGraph.zig`): Non-manifold cellular complex of `Vertex`, `Edge`, and `Face` cells linked by explicit incidence lists (`vertex_incident_edges`, `edge_incident_vertices`, `edge_incident_faces`, `face_incident_edges`, `face_incident_edges_dir`). Used notably to represent medial axis skeletons.

## Geometry & Rendering Terms

- **QEM / SQEM**:
  - **QEM** (`src/models/surface/qem.zig`): Garland–Heckbert Quadric Error Metric (`Mat4f`) regularized with line quadrics, used for mesh decimation.
  - **SQEM** (`src/geometry/SQEM.zig`): Spherical Quadric Error Metric over 4D spheres $(c_x, c_y, c_z, r)$, used by Variational Medial Axis Skeleton (**VMAS**) algorithms.
- **`View`** (`src/rendering/View.zig`): Manages the 3D viewport, `Camera`, offscreen color/depth `FBO`, infinite ground grid, mouse/wheel navigation, screen-to-world unprojection, and the `needs_redraw` dirty flag.
- **`Shader.Parameters`**: Per-instance struct exposed by every shader wrapper under `src/rendering/shaders/`. Holds a pointer to the lazy singleton compiled `Shader`, its own `VAO`, and uniform state, decoupling GPU program compilation from per-model rendering settings.
- **`IBO.cell_index_buffer_index`**: Secondary OpenGL buffer stored inside `IBO` mapping each drawn primitive (`gl_PrimitiveID`) back to its logical cell index (e.g., polygonal face ID across fan-triangulated triangles), read via a `TextureBuffer` in per-face shaders.
